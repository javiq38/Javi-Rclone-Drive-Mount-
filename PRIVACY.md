# Privacy Policy — Javi Rclone Drive Mount

_Last updated: September 1, 2026_

This project is a personal utility that uses `rclone` to mount Google Drive on a single Linux machine for personal, non-commercial use.

- This application is used solely by its owner (a single Google account) and is not distributed publicly.
- It accesses Google Drive data only to read, write, and sync files as directed by the local `rclone` configuration on the owner's own machine.
- No data accessed through this application is shared with, sold to, or processed by any third party.
- No data is used for advertising or analytics.
- All data handled by this application remains under the sole control of its owner.
- OAuth credentials and tokens are stored locally on the owner's machine and are not transmitted elsewhere.
